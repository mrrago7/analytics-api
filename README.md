# Analytics API

REST API для загрузки и анализа данных из CSV и Excel файлов.

## Возможности

- загрузка CSV и Excel файлов;
- хранение загруженных файлов в PostgreSQL;
- расчёт среднего значения;
- расчёт медианы;
- расчёт корреляции;
- сохранение результатов анализа в PostgreSQL;
- очистка данных от дубликатов и пропусков;
- CRUD-операции с файлами.

## Технологии

- Python
- Flask
- Pandas
- SQLAlchemy
- PostgreSQL

## Установка

Установить зависимости:

pip install -r requirements.txt

## Запуск

Запустить приложение командой:

python -m flask --app ./app.py run

После запуска API будет доступен по адресу:

http://127.0.0.1:5000

## API endpoints

### Загрузка файла

POST /upload

Загружает CSV или Excel файл и сохраняет его в PostgreSQL.

### Статистика

GET /data/stats?file_id=<id>

Рассчитывает среднее значение, медиану и корреляцию для числовых данных.

### Очистка данных

GET /data/clean?file_id=<id>

Удаляет дубликаты и заполняет пропущенные значения.

### Получение файла

GET /files/<file_id>

Возвращает информацию о загруженном файле.

### Обновление файла

PUT /files/<file_id>

Обновляет загруженный файл.

### Удаление файла

DELETE /files/<file_id>

Удаляет файл из базы данных.
